# Changelog

## [1.2.0] - 13.04.2026

### Added
- Adjusted window title bar with use of "tauri_plugin_decorum" (for Windows and macOS only)
- Updated all icons with lucide (eliminates dependency to "noto-fonts-emoji" on Linux)

- Enhancements in the color scheme
